## Choosing a file

- **Product images:** start with the model-specific JPG. Notebook PNGs are smaller and do not contain transparent backgrounds.
- **Logos:** start with `logo_1024.png` for layout review and `logo_300.png` for a compact preview. All supplied logo PNGs are fully opaque, including files whose names suggest transparency.
- **Icons:** ICO files are application icons, not full-resolution product photographs. Listed dimensions refer to the largest selected icon image.
- **Videos:** preview the complete clip to confirm spoken language, subtitles, and suitability for the intended audience. Filename labels alone are not language verification.
- **Listings:** preserve aspect ratio and check the retailer’s image requirements. Confirm the final product configuration before using an illustration as a listing image.

No SVG/vector logo, separate subtitle file, or verified transparent cutout is included in the tracked asset library.

## Complete library and exact file identification

[Download all repository files as a ZIP](https://github.com/wuxiaolong1117/assets-for-IDMA/archive/refs/heads/main.zip). This includes the B&H procurement workbook as well as marketing assets.

The [asset manifest](asset-manifest.json) records each original file’s path, size, SHA-256 checksum, direct URL, and image dimensions where applicable. A matching checksum confirms that two copies contain the same bytes.

Original filenames are retained so existing GitHub links continue to work. Use the descriptive labels in this guide when sharing files. Direct links follow the latest main branch; use a commit-specific link when an exact handoff revision is needed.
